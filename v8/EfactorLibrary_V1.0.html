1. Adding Efactor Library to Your Project

The Efactor Library is hosted on a custom Ivy repository. Follow these steps to integrate it into your Android project.

Step 1: Configure Ivy Repository

Add the following in your project-level build.gradle file:

repositories {
    ivy {
        url "https://efactor.tech/v8/download.php/${CUSTOMER_ID}/${ACCESS_KEY}/"

        patternLayout {
            artifact "[artifact]-[revision].[ext]" 
        }

        metadataSources {
            artifact() 
        }
    }
}

2. Adding Efactor Library

Include the library dependency in your app-level build.gradle file:

dependencies {
    implementation 'proto:efactorprotov2:1.3@aar'
}

✅ This ensures that the Efactor Library is downloaded and linked correctly.

3. Adding Required Dependencies

Since the Efactor Library depends on external libraries, app developers must manually include them in their project.

Add the following dependencies in your app-level build.gradle file:

dependencies {

4. Adding a Device

To add a device, follow these steps:

Step 2: Initialize Provision Manager

Before adding a device, initialize the EfactorProvisionManager in your Activity or Fragment:

libraryManager = EfactorLibraryManager.init(this, api_key);
provisionManager = EfactorProvisionManager.getInstance(getApplicationContext());

Step 3: Scan QR Code

If the device provides a QR code, scan and decode it using:

provisionManager.decodeScannedQrData(scannedData);

✅ Once the data is processed, the device will be verified by the Efactor cloud.

sendData Operations

The following operations are supported:

  1. ADD_DEVICE
  2. REMOVE
  3. SEND_DATA
  4. GET_CONNECTIVITY_STATUS
  5. ADD

1: ADD_DEVICE

To add a device, ApiKey, NodeId, and ApiKey should not be null.

2: REMOVE

To remove a device, ApiKey, NodeId, and DeviceId should not be null.

3: SEND_DATA

To send data, Payload, ParamName, PageName, ApiKey, NodeId, Latitude, and Longitude should not be empty or null.

4: GET_CONNECTIVITY_STATUS

To get connectivity status, NodeId, Latitude, and Longitude should not be empty or null.

5: ADD

To add a device to the network, ApiKey, NodeId, and SecretKey should not be null.

Example Code

EfactorLibraryManager.getInstance().sendData(req, new ApiLibResponseListener() {
    @Override
    public void onSuccess(Bundle response) {
        Log.d("Efactor", "Device Connected: " + response);
    }

    @Override
    public void onResponseFailure(Exception e) {
        Log.e("Efactor", "Device Connection Failed: " + e.getMessage());
    }

    @Override
    public void onNetworkFailure(Exception e) {
        Log.e("Efactor", "Network Error: " + e.getMessage());
    }
});

5. Connecting Device to Network

After adding the device, follow these steps to connect it to a network:

Step 4: Start Provisioning Process

Once the device is added, follow these steps to connect it to a Wi-Fi network:

1: ProvisionLanding

private void connectDevice() {
    btnConnect.setEnabled(false);
    btnConnect.setAlpha(0.5f);
    txtConnectBtn.setText(R.string.btn_connecting);
    progressBar.setVisibility(View.VISIBLE);

    if (ActivityCompat.checkSelfPermission(ProvisionLanding.this, Manifest.permission.ACCESS_FINE_LOCATION) 
        == PackageManager.PERMISSION_GRANTED) {
        provisionManager.getEfactorDevice().getcrds();
    } else {
        Log.e(TAG, "Not able to connect device as Location permission is not granted.");
        Toast.makeText(ProvisionLanding.this, 
                       "Please give location permission to connect device", 
                       Toast.LENGTH_LONG).show();
    }
}
